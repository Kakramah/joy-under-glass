# حين يُراقَب الضوء
موقع عربي أدبي بصري عن الفرح والحسد وحدود الإفصاح، بأسلوب أصلي: أطلس الزجاج والضوء. صفحة ثابتة تعمل دون خدمات خارجية.

المعاينة: `python3 -m http.server 8047` ثم `http://localhost:8047`.

التحقق: `python3 scripts/check.py` ثم `bash ~/khaldoun-projects/khaldoun-web-starter/scripts/بوابة-الويب.sh` من جذر المشروع؛ نتيجة المتصفح والبوابة في REVIEW.md.

الخطوط Amiri وTajawal محلية بترخيص SIL OFL، والترخيصان في fonts. الصور الأصلية مولدة بالأداة المدمجة، والأوصاف في ASSET-PROMPTS.md، ولا تعد وثائق. عبارة خلدون أصل الفكرة، والنثر الممتد أُعدّ للموقع. العقاب المعدني والأفاتار والتوقيع أصول معتمدة.

المستودع خاص، وPages لم يُفعّل. لا نشر عام قبل موافقة خلدون، وكل تعديل في فرع وطلب دمج. نُسخ حماية القالب محفوظة بعد رفض إزالتها آلياً، والقواعد السارية والبوابة تُقرأ وتُشغّل من القالب الأصلي وحده.
